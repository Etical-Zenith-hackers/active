How to Check a Cryptocurrency Transaction Before Reporting a Scam

A practical checklist for verifying a cryptocurrency transaction before submitting a fraud report or beginning an investigation.

# Confirm the transaction hash

Start by locating the transaction ID or TXID.

Avoid relying solely on a screenshot.

Confirm the blockchain network

Make sure the transaction belongs to the correct network.

This is especially important when the same asset exists on multiple networks.

Verify the amount

Compare the amount shown on the blockchain with the amount you intended to send.

Verify the addresses

Check the sending and receiving addresses carefully.

Record them exactly as displayed.

Check confirmation status

Determine whether the transaction is pending, confirmed or otherwise shown differently by the relevant blockchain.

Preserve the original records

Save the transaction hash, wallet information, exchange records and communications.

Document the reason for the report

Write a short factual explanation describing what happened and why the transaction is believed to be unauthorized or fraudulent.

Final thoughts

Accurate transaction verification can prevent errors and give investigators a reliable starting point.
