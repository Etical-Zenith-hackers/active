\\## How to Trace a Crypto Wallet Using Only a Transaction Hash

A transaction hash can provide a useful starting point for a cryptocurrency investigation.

It allows a specific blockchain transaction to be located and examined.

\\### Find the Hash

Retrieve the transaction hash from your wallet, exchange, or payment record.

\\### Identify the Blockchain

Determine which blockchain network processed the transaction.

\\### Review the Addresses

Examine the sender and recipient addresses associated with the transaction.

\\### Follow the Relevant Asset

Review later transfers involving the relevant asset and receiving addresses.

\\### Preserve the Evidence

Record the transaction hash, addresses, amount, timestamp, network, and relevant screenshots.

\\### Add Context

Blockchain information should be combined with emails, messages, exchange records, invoices, and other evidence where available.
